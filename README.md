## 🎯 Objective

Create a scalable multi-agent system that autonomously completes surveys across multiple platforms using browser automation, with real-time monitoring and instant cashout capabilities.

## 🎨 React Dashboard

A modern, real-time dashboard for monitoring and controlling automated survey completion agents. Built with React, TypeScript, and Tailwind CSS with a cyberpunk-inspired neon design system.

### Dashboard Features
- **Real-time Agent Monitoring**: Track multiple survey completion agents simultaneously
- **Live Browser Streaming**: Real-time screenshots of active browser sessions
- **Performance Metrics**: Detailed metrics for earnings, completion rates, and system performance
- **Neon Design System**: Cyberpunk-inspired UI with glowing effects and animations
- **Responsive Layout**: Mobile-friendly interface with adaptive grid system

## 🚀 Quick Start

### Prerequisites
- Node.js >= 18.0.0
- npm or yarn

### Installation

1. Install dependencies:
```bash
npm install
```

2. Start the dashboard development server:
```bash
npm run dashboard
```

3. Open your browser and navigate to `http://localhost:3000`

### Available Scripts

- `npm run dashboard` - Start React dashboard development server
- `npm run dashboard:build` - Build dashboard for production
- `npm run dashboard:preview` - Preview production build
- `npm run start` - Start backend automation system
- `npm run dev` - Start backend in development mode
